## Steps
1. The team lead (Mohamed Kassas) pushes the BASE project to `main` first (zip `bloodlink_00_base_main.zip`).
   If the base is already on GitHub, skip this: just pull `main`.
2. You clone the repo:
   git clone https://github.com/<your-org>/Esprit-PW-2A11-2026-2027-BloodLink.git
   cd Esprit-PW-2A11-2026-2027-BloodLink
3. Create your branch:
   git checkout -b feature/module-1-campagnes-sponsors
4. Unzip this zip INSIDE the repo folder (accept replacing files; the folders app/ are merged).
5. Commit and push:
   git add .
   git commit -m "feat: module 1 Campagnes et sponsors"
   git push -u origin feature/module-1-campagnes-sponsors
6. On GitHub, open a Pull Request into `develop` (or `main`), write "Closes #<issue number>", ask a teammate to review, then merge.
7. Move your issue to Done in the Project board.
